## About the course

This two-day, 16-hour course helps learners define a sustainability-reporting objective and boundary, apply the GRI Universal and Topic Standards, build evidence-controlled disclosures, and review a report for approval and submission. The materials incorporate the original trainer deck, the supplied reference ebooks, current Singapore reporting requirements, and public reporting examples from CDL, Singtel, and DBS.

## Learning outcomes

By the end of the course, learners will be able to:

1. Identify the objectives of sustainability reports, report users, organisational procedures, reporting boundaries, and relevant sustainability-reporting requirements.
2. Structure a GRI-aligned sustainability report and collaborate with stakeholders to determine material topics and disclosure evidence.
3. Proofread, review, approve, and submit a sustainability report using a controlled evidence and release process.

## Assessment

The summative assessment comprises a 60-minute Written Assessment with five open-ended questions and a 60-minute Case Study with three open-ended questions. Candidate papers are delivered through the LMS. Assessment answer keys are trainer-only and are intentionally excluded from this learner repository.
